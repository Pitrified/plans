# Neovim 0.12 from the upstream tarball

- **Goal** - Neovim 0.12.6 and the `tree-sitter` CLI 0.27.1 on this box, replacing the apt `neovim` 0.11.6 from `2026-11-03_00_install_neovim.md`, for the vim to Neovim migration (`~/dotfiles/plans/02-modernize-vim-setup/`, decision 14).

## Decisions

- Why not apt: nvim-treesitter's `main` branch needs Neovim 0.12+ and tree-sitter-cli 0.26.1+.
  Ubuntu 26.04 apt has Neovim 0.11.6 and tree-sitter-cli 0.25.9; the Neovim stable PPA stopped at 22.04.
- Neovim: upstream release tarball `nvim-linux-x86_64.tar.gz` v0.12.6,
  sha256 `474430d53e6264f6d6dd18db42d6dc9df3a1b56ca9e88a325bbf860e1a811d87` (GitHub release asset digest).
  Not the AppImage (needs FUSE) and not snap.
- tree-sitter: release asset `tree-sitter-linux-x64.gz` v0.27.1 (the single gzipped binary),
  sha256 `d01042f94ba3d6827ddc9788e235f75d8366431be42bdf90ade534d960c98b7d`.
- Location, all user-owned, no sudo:
  - `~/.local/opt/nvim-0.12.6/` holds the unpacked tarball (versioned folder, so an upgrade is a new folder plus a relink).
  - `~/.local/bin/nvim` symlinks to `~/.local/opt/nvim-0.12.6/bin/nvim`.
  - `~/.local/bin/tree-sitter` is the binary itself.
- PATH: no change. `~/.local/bin` is already on PATH ahead of `/usr/bin`.
- The apt `neovim` and `neovim-runtime` are removed (sudo-handoff), so only one `nvim` exists.
- Downloads go to a fresh empty folder in the session scratchpad and are checked against the digests before unpacking.

## Steps

Claude, unprivileged:

1. Download both assets into a new empty scratch folder; `sha256sum` each and compare with the digests above; stop on mismatch.
2. `mkdir -p ~/.local/opt`; unpack the tarball and move `nvim-linux-x86_64/` to `~/.local/opt/nvim-0.12.6`.
3. `ln -s ~/.local/opt/nvim-0.12.6/bin/nvim ~/.local/bin/nvim`.
4. `gunzip` the tree-sitter binary to `~/.local/bin/tree-sitter`; `chmod +x`.
5. Verify: `nvim --version` (v0.12.6, resolved from `~/.local/bin`), `tree-sitter --version` (0.27.1).

User (sudo-handoff), after step 5 passes:

    sudo apt-get remove --purge -y neovim neovim-runtime 2>&1 | tee ~/handoff-logs/09a-apt-remove-neovim.log

Verify: `dpkg -l neovim` shows it gone; `command -v nvim` is `~/.local/bin/nvim`.

## Rollback

    rm ~/.local/bin/nvim ~/.local/bin/tree-sitter
    rm -r ~/.local/opt/nvim-0.12.6

and, to go back to apt: `sudo apt-get install -y neovim`.
No config is written; `~/.config/nvim` does not exist yet.
