# Phase 4 - Stage G7

## Overview

Clone the repos, copy the data git does not hold, and bring nginx and Gramps up on G7 loopback.
No tunnel runs on G7 in this phase: the tunnel is shared with G4 (`00_start.md` Q2), and two connectors would split live traffic.
The Gramps data copied here is a rehearsal copy; phase 5 replaces it with the frozen one.
Context: [`00_start.md`](00_start.md) Q4, Q12. Depends on [`02_g4_trusted.md`](02_g4_trusted.md), [`03_g7_install.md`](03_g7_install.md).

## Goals

1. Every repo in `repos.toml` is cloned on G7 over ssh, in an `ssh -A` session from G4.
2. The curated gitignored data, `~/cred` and the home data are on G7.
3. nginx serves the landing page and cc-kb on G7 loopback.
4. Gramps Web runs on G7 loopback from a copy of `/srv/gramps-web` and the same `.env` secret key.

  Check that repomgr clones with ssh URLs (or plain `git clone git@github.com:...` where it does not); private repos included.
  Branches: check out the branch each repo is on today on G4 (`abyss`, `lang-tools`, `snap_fit` are not on main).

  - Home: `~/cred`, `~/data`, `~/ephem`, `~/other`, `~/opencamera_backups`, `~/handoff-logs`, `~/cf-setup-logs`, `~/saved_state_g4`.
  - Gitignored repo data (inventory of 2026-10-14, rerun the scan before copying):
    `abyss/cache/`,
    `controcanto/kb/sources/` and `controcanto/docs/kb/`,
    `epub-fixer/books/*/` (renderings and work),
