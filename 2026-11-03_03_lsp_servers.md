# Language servers and shfmt for the Neovim config

- **Goal** - the servers and formatter phase 4 of the Neovim migration calls on this box: basedpyright, gopls, lua-language-server, bash-language-server (with node and npm), shfmt; plan `~/dotfiles/plans/02-modernize-vim-setup/04_lsp_and_completion.md`, step 1 (decision 34).
  ruff and shellcheck are already installed; the Dart server ships with `~/flutter`.

## Decisions

- basedpyright 1.40.2 with `uv tool install` (decision 22): binaries `basedpyright` and `basedpyright-langserver` in `~/.local/bin`.
- gopls v0.24.0 with `go install`: binary in `GOBIN=~/go/bin`, already on PATH.
- lua-language-server 3.19.2 from the GitHub release (not in apt): asset `lua-language-server-3.19.2-linux-x64.tar.gz`,
  sha256 `93ad326b10f6c00911dd8c450fa098332dbd8f9f45d1052f5636a2d54479b947` (release asset digest).
  Unpacked into `~/.local/opt/lua-language-server-3.19.2/` (versioned folder, as for Neovim), linked from `~/.local/bin/lua-language-server`.
  If the binary does not find its scripts through the symlink, a two-line `exec` wrapper script takes the link's place.
- nodejs 22.22.1, npm 9.2.0 and shfmt 3.12.0 from apt (sudo-handoff): security updates through apt; bash-language-server needs node >= 20.
- bash-language-server 5.8.1 with `npm install -g --prefix ~/.local`: binary in `~/.local/bin`, packages in `~/.local/lib/node_modules`, no root.
  The prefix is passed on the command line; no `~/.npmrc` is written.
- No shell rc or PATH change.
- Downloads go to a fresh empty folder in the session scratchpad and are checked against the digest before unpacking.

## Steps

User (sudo-handoff):

    sudo apt-get install -y nodejs npm shfmt 2>&1 | tee ~/handoff-logs/11a-apt-node-shfmt.log

Claude, unprivileged:

1. `uv tool install basedpyright==1.40.2`.
2. `go install golang.org/x/tools/gopls@v0.24.0`.
3. Download the lua-language-server asset into a new empty scratch folder; `sha256sum` it against the digest above, stop on mismatch.
4. Unpack into `~/.local/opt/lua-language-server-3.19.2/`; `ln -s ~/.local/opt/lua-language-server-3.19.2/bin/lua-language-server ~/.local/bin/lua-language-server`.
5. After the apt log checks out: `npm install -g --prefix ~/.local bash-language-server@5.8.1`.
6. Verify each resolves to the expected path and prints its version:
   `basedpyright --version`, `gopls version`, `lua-language-server --version`, `node --version`, `bash-language-server --version`, `shfmt --version`.

## Rollback

    sudo apt-get remove --purge -y nodejs npm shfmt
    sudo apt-get autoremove --purge -y
    uv tool uninstall basedpyright
    rm ~/go/bin/gopls
    rm ~/.local/bin/lua-language-server
    rm -r ~/.local/opt/lua-language-server-3.19.2
    npm uninstall -g --prefix ~/.local bash-language-server

The npm uninstall goes before removing node.
