# gsplat training environment on g7

## Goal

A user-level environment that trains Gaussian splats on g7's GPU with gsplat, for abyss's `plans/05_threejs_scene` phase 2.

## Decisions

- No sudo and nothing system-wide: a git clone plus a uv `.venv` inside it. CUDA toolkit 13.1 and COLMAP 3.12.6 are already installed (`2026-11-10_00_cuda_colmap`).
- Location `~/repos/gsplat`: a clone of `nerfstudio-project/gsplat` at `main` commit `512d366b67` (2026-09-19), pinned by checkout, not the 1.5.3 release (2025-07), because the training script lives in the repo's `examples/` and tracks `main`.
- Python 3.12 (uv-managed, already present). torch 2.9.1 + torchvision 0.24.1 from `https://download.pytorch.org/whl/cu130`: the versions gsplat's `examples/requirements.txt` pins. Local nvcc 13.1 matches torch's CUDA major (13).
- `CUDA_HOME=/usr/local/cuda` set per command, not in any shell rc.
- Data and outputs in `~/data/splat_train/`, outside every repo.
- Nothing touches PATH, shell rc, systemd or cron.

## Steps

1. `git clone https://github.com/nerfstudio-project/gsplat ~/repos/gsplat`, `git -C ~/repos/gsplat checkout 512d366b67`, submodules.
2. `uv venv --python 3.12` in it; `uv pip install torch==2.9.1 torchvision==0.24.1 --index-url https://download.pytorch.org/whl/cu130`.
3. `CUDA_HOME=/usr/local/cuda uv pip install --no-build-isolation -e .` (builds gsplat's kernels), then `uv pip install --no-build-isolation -r examples/requirements.txt` (builds fused-ssim, fused-bilagrid, ppisp).
4. Check: `import gsplat, torch; torch.cuda.is_available()`, and a tiny rasterization call.

## Rollback

- `rm -rf ~/repos/gsplat ~/data/splat_train`.
- uv's cache (`uv cache clean torch` etc.) if the disk space is wanted back.
