# Host facts - g7

A capture of what was run on the host on 2026-10-09 while deciding whether GPU
passthrough was viable. Side-document of phase 1: no status.

## Machine

- HP ZBook Studio G7, hostname `pmn-G7`, user `pmn`.
- 10th-gen Intel Core (Comet Lake), 32 GB RAM. Core count not captured.
- NVMe: Phison E12. Free space not captured.
- NVIDIA driver 580.178.04 on the host.

## GPU

```
01:00.0 VGA compatible controller [0300]: NVIDIA Corporation TU106GLM [Quadro RTX 3000 Mobile / Max-Q] [10de:1f36] (rev a1)
	Subsystem: Hewlett-Packard Company TU106GLM [Quadro RTX 3000 Mobile / Max-Q] [103c:8738]
	Kernel driver in use: nvidia
	Kernel modules: nvidiafb, nouveau, nvidia_drm, nvidia
```

- 6 GB VRAM.
- It is the **only** GPU listed. The CPU has an integrated one, but there is no
  `00:02.0` device, so the BIOS is most likely set to discrete-only graphics.
- The desktop runs on it: `Xorg`, `gnome-shell` and a browser showed in
  `nvidia-smi`. Passing it through with the desktop up kills the session, which
  is why the GPU mode starts from a headless boot.

## IOMMU

- On: 21 groups in `/sys/kernel/iommu_groups`.
- Group 1 holds the card's four functions and its root port, nothing else:

```
group 1: 00:01.0 PCI bridge [0604]: Intel Corporation 6th-10th Gen Core Processor PCIe Controller (x16) [8086:1901] (rev 02)
group 1: 01:00.0 VGA compatible controller [0300]: NVIDIA Corporation TU106GLM [Quadro RTX 3000 Mobile / Max-Q] [10de:1f36] (rev a1)
group 1: 01:00.1 Audio device [0403]: NVIDIA Corporation TU106 High Definition Audio Controller [10de:10f9] (rev a1)
group 1: 01:00.2 USB controller [0c03]: NVIDIA Corporation TU106 USB 3.1 Host Controller [10de:1ada] (rev a1)
group 1: 01:00.3 Serial bus controller [0c80]: NVIDIA Corporation TU106 USB Type-C UCSI Controller [10de:1adb] (rev a1)
```

- All four functions leave the host together. Their IDs:
  `10de:1f36,10de:10f9,10de:1ada,10de:1adb`.
- The USB-C controller on the card suggests the external display ports are
  wired to it. Irrelevant while the host is headless.

## Commands used

```bash
lspci -nnk | grep -A3 -Ei 'vga|3d|display'
ls /sys/kernel/iommu_groups | wc -l
for d in /sys/kernel/iommu_groups/*/devices/*; do
  g=${d#*/iommu_groups/}; g=${g%%/*}
  printf 'group %s: ' "$g"; lspci -nns "${d##*/}"
done | sort -V
cat /sys/module/kvm_intel/parameters/nested
nvidia-smi
```
