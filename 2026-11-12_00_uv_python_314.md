# uv-managed Python 3.14

## Goal

Give uv a CPython 3.14 that ships its headers, so laife's `make sync` can build pygame 2.6.1 from source (no cp314 wheel).

## Decisions

- uv-managed CPython 3.14.8 rather than `apt install python3.14-dev`: no sudo, user-level, same mechanism as the 3.12 and 3.13 uv already manages here.
- Installed under `~/.local/share/uv/python/`. No PATH or shell rc change (no `--default`), so `/usr/bin/python3` stays the system 3.14.4.
- uv's default `python-preference = managed` then picks 3.14.8 over the system one for every uv project asking for 3.14. That affects other repos on 3.14 at their next venv recreation; existing venvs are unchanged.

## Steps

    uv python install 3.14
    cd ~/repos/laife; make sync   # recreates .venv on the managed interpreter

## Rollback

    uv python uninstall 3.14
    rm -rf ~/repos/laife/.venv
